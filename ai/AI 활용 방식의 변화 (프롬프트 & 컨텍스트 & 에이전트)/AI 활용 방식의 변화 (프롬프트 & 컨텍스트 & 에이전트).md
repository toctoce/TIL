# AI 활용 방식의 변화 (프롬프트 & 컨텍스트 & 에이전트)

AI 활용 방식의 변화는 크게 아래 세 단계로 볼 수 있다.

```text
프롬프트 시대
= AI에게 어떻게 말할 것인가

컨텍스트 시대
= AI에게 어떤 정보를 줄 것인가

에이전트 시대
= AI가 어떤 도구를 사용해 어떻게 행동하게 할 것인가
```

## 1단계: 프롬프트 시대

프롬프트 시대의 핵심은 AI에게 어떻게 말할 것인가이다.

초기에는 AI가 외부 정보나 도구를 적극적으로 사용하기보다는,
사용자가 입력한 질문을 바탕으로 답변을 생성하는 방식이 중심이었다.

그래서 중요한 것은 질문을 얼마나 잘 쓰느냐였다.

예를 들어 그냥 이렇게 묻는 것보다,

```text
TCP 설명해줘.
```

이렇게 묻는 것이 더 좋은 답변을 얻기 쉬웠다.

```text
너는 백엔드 면접관이야.
TCP 3-way handshake를 초보자도 이해할 수 있게 설명해줘.
마지막에는 면접 답변용으로 3문장 요약도 해줘.
```

즉, 이 시기에는 AI에게 역할을 부여하고, 원하는 형식을 지정하고, 답변의 수준을 조절하는 능력이 중요했다.

## 2단계: 컨텍스트 시대

그런데 프롬프트를 아무리 잘 써도 한계가 있다.

AI가 모르는 정보, 최신 정보, 내 프로젝트의 코드, 회사 내부 문서 같은 것은
질문만 잘한다고 정확히 알 수 없기 때문이다.

예를 들어 이렇게 물어보면 답변이 애매할 수 있다.

```text
내 프로젝트 테스트가 왜 실패하는지 알려줘.
```

AI는 네 프로젝트의 코드도 모르고, 테스트 로그도 모르고, 최근 변경 사항도 모른다.

그래서 컨텍스트 시대에는 질문보다 어떤 컨텍스트를 함께 제공하느냐가 중요해진다.

컨텍스트에는 대화 기록, 시스템 지시, 코드, 로그, 검색 결과, 도구 실행 결과 등이 포함될 수 있다.

```text
이 테스트 로그를 보고,

관련 테스트 파일과 서비스 코드를 참고해서,

왜 실패하는지 분석해줘.
```

즉, 컨텍스트 시대에는 AI에게 단순히 질문을 던지는 것이 아니라,
판단에 필요한 자료를 잘 넣어주는 것이 중요하다.

## 3단계: 에이전트 시대

에이전트 시대에는 AI가 단순히 답변만 하지 않는다.

이제 AI는 목표를 받고, 필요한 정보를 찾고, 도구를 사용하고, 결과를 확인하면서 작업을 진행한다.

예를 들어 사용자가 이렇게 요청한다고 해보자.

```text
이 프로젝트에서 실패하는 테스트를 찾아서 원인을 분석하고 수정해줘.
```

챗봇은 보통 설명을 해준다.

```text
테스트 실패 원인은 이런 가능성이 있습니다.
```

하지만 에이전트는 직접 행동한다.

```text
1. 테스트 명령어를 확인한다.
2. 테스트를 실행한다.
3. 실패 로그를 읽는다.
4. 관련 테스트 파일을 찾는다.
5. 구현 코드를 확인한다.
6. 원인을 추론한다.
7. 코드를 수정한다.
8. 다시 테스트를 실행한다.
9. 최종 결과를 보고한다.
```

즉, 에이전트 시대의 핵심은 **AI가 도구를 사용해서 일을 수행한다는 것**이다.

### 에이전트가 사용하는 도구 예시

```text
파일 읽기, 파일 수정, 터미널 실행, 테스트 실행, Git diff 확인, GitHub 이슈 조회, PR 생성, DB 조회, 캘린더 일정 등록, Notion 문서 검색 ...
```

### 에이전트 시대에 중요한 것

에이전트가 도구를 사용할 수 있게 되면 편리하지만, 동시에 위험도 생긴다.

예를 들어 AI가 마음대로 파일을 삭제하거나, DB를 수정하거나, 잘못된 코드를 커밋하면 문제가 된다.

그래서 에이전트 시대에는 단순히 “AI가 똑똑한가?”보다 이런 질문이 더 중요해진다.

- 어떤 도구를 허용할 것인가?
- 어떤 파일까지 접근하게 할 것인가?
- 위험한 작업은 승인받게 할 것인가?
- 테스트는 자동으로 실행할 것인가?
- 결과를 어떻게 검증할 것인가?
- 실패하면 어떻게 되돌릴 것인가?

이 부분이 바로 AI가 도구를 안전하고 안정적으로 쓰도록 실행 흐름을 설계하는 **하네스 엔지니어링**으로 이어진다.

## 세 시대 비교

| 구분      | 핵심 질문      | AI의 역할        | 중요한 능력                 |
| ------- | ---------- | ------------- | ---------------------- |
| 프롬프트 시대 | 어떻게 말할까?   | 답변 생성         | 질문을 잘 쓰는 능력            |
| 컨텍스트 시대 | 무엇을 알려줄까?  | 주어진 정보 기반 분석  | 필요한 정보를 잘 제공하는 능력      |
| 에이전트 시대 | 어떤 일을 맡길까? | 도구를 사용해 작업 수행 | 도구, 권한, 검증 흐름을 설계하는 능력 |
