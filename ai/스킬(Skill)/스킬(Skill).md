# Skill

스킬은 LLM이 특정 작업을 안정적으로 반복 수행하기 위한 지침, 워크플로, 리소스의 묶음이다.
프로세스를 한 번만 설정해 두면 해당 작업이 필요할 때마다 처음부터 설명할 필요 없이 안정적으로 적용할 수 있다.

## 구성 요소

- **이름 및 설명**: LLM이 해당 작업에 적절한 스킬인지 판단하는 기준이 됩니다.
- **워크플로 지침**: 보통 SKILL.md 파일에 작성되며, 작업을 수행하기 위한 단계별 가이드를 담고 있습니다.
- **리소스**: 템플릿, 예시, 브랜드 가이드라인, 스키마, 도구 액세스 등 워크플로 수행에 필요한 참고 자료입니다.

## 장점

- **일관성**: 특정 섹션의 누락을 방지하고, 톤이나 형식이 흐트러지지 않도록 관리해 선호하는 형식을 준수합니다. 
- **내장 모범 사례 적용**: 일반 사용자가 사용하기에도 적절할 만큼 간편하지만, 도메인 전문가(SME)가 검토한 워크플로를 기반으로 합니다. 
- **플레이북 공유**: 팀원들이 비공식 지식이나 문서화되지 않은 지식에 의존하지 않고, LLM 환경에서 동일한 표준 프로세스를 공유하여 협업할 수 있습니다. 
- **범용적 재사용**: 한 번 구축해 두면 여러 유사한 사례에 반복 적용할 수 있다.

## SKILL.md

> 스킬의 플레이북. LLM이 워크플로를 일관되게 실행하도록 안내하는 텍스트 지침.

마크다운 기반이라 이식성이 뛰어나다. 공유, 버전 관리가 간편하며 다양한 도구에서 재사용 가능하다.

일반적으로 아래 내용들이 정의된다.
- 스킬의 기능
- 필수 입력 항목
- 단계별 안내
- 필수 출력 형식
- 완료 전 최종 점검 사항

> 스킬은 필요에 따라 조합할 수 있는 작은 구성 요소로 나눌 때 가장 효과적이다. 거대한 구조의 스킬을 작게 분할하자.

[더치페이 가격을 계산하는 스킬(calculate-amount)](<스킬(Skill)/calculate-amount/SKILL.md>)을 만들어보았다.(AI로 생성)

이제 스킬을 사용해서 계산하라고 입력하면,
```text
calculate-amount 스킬 써서 1000원 3000원 5000원 10000원 4명 계산해줘
```
계산한 후 설정한 포맷대로 출력한다.
```text
총액: 19,000원
1인당: 4,750원
```

> 스킬을 사용하라고 명시하지 않아도 사용하게끔 하려면 전역 스킬 위치인 `~/.codex/skills/<skill-name>/`로 옮기면 된다.
