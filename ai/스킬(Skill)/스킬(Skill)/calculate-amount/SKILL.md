# 금액 계산

## 개요

필수 입력값을 바탕으로 식사비나 공동 지출 금액을 계산하고, 한국 원화 금액을 지정된 형식으로 출력합니다.

## 필수 입력값

계산 전에 아래 세 가지 값을 확인하거나 문맥에서 추론합니다.

1. `가격`: 기준 금액.
2. `덧셈`: 추가로 더할 금액. 사용자가 추가 금액이 없다고 명확히 말한 경우에만 `0`으로 처리합니다.
3. `몇명이서 먹었는지`: 금액을 나눌 인원수.

필수 입력값이 빠졌거나 모호하면 최종 계산을 반환하기 전에 짧게 확인 질문을 합니다.

## 계산 절차

1. 숫자 입력값에서 쉼표, 공백, `원` 등 표시용 문자를 제거합니다.
2. `가격`과 `덧셈`이 0 이상의 숫자인지 확인합니다.
3. `몇명이서 먹었는지`가 양의 정수인지 확인합니다.
4. `총액 = 가격 + 덧셈`으로 계산합니다.
5. `1인당 금액 = 총액 / 인원수`로 계산합니다.
6. 나누어떨어지지 않으면 적용한 반올림 규칙을 함께 표시합니다. 사용자가 별도 규칙을 말하지 않았다면 결제 금액은 원 단위 올림을 우선 적용합니다.
7. 모든 원화 금액은 세 자리마다 쉼표를 넣고 끝에 `원`을 붙입니다.

## 출력 형식

간결한 한국어로 출력합니다. 사용자가 특정 값만 요청하지 않았다면 총액과 1인당 금액을 함께 표시합니다.

필수 금액 형식:

```text
12,345원
```

권장 응답 형식:

```text
총액: 00,000원
1인당: 00,000원
```

올림을 적용한 경우:

```text
총액: 00,001원
1인당: 10,001원 (원 단위 올림)
```

## 최종 품질 점검

응답 전에 아래 항목을 확인합니다.

1. 필수 입력값 세 가지인 `가격`, `덧셈`, `인원수`를 모두 사용했는지 확인합니다.
2. 총액이 `가격 + 덧셈`과 일치하는지 확인합니다.
3. 1인당 금액이 지정된 인원수로 계산됐는지 확인합니다.
4. 모든 금액에 세 자리마다 쉼표가 들어갔는지 확인합니다.
5. 모든 금액이 `원`으로 끝나는지 확인합니다.
6. 나누어떨어지지 않는 경우 적용한 올림 또는 반올림 규칙을 명확히 표시했는지 확인합니다.
