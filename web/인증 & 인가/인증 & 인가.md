# 인증 & 인가

> 인증(Authentication): 사용자가 누구인지 확인하는 것
> 
> 인가(Authorization): 사용자가 무엇을 할 수 있는지 확인하는 것

인증과 인가는 ID 및 액세스 관리(IAM)의 핵심 개념이다. 둘 다 ID 보안과 관련이 있지만, 서로 대체할 수 있는 개념은 아니다.

먼저 사용자가 자신의 신원을 증명하는 인증이 이루어지고, 그 다음 사용자의 권한에 따라 접근할 수 있는 범위를 결정하는 인가가 진행된다.

| 비교 항목 | 인증(AuthN) | 인가(AuthZ) |
| --- | --- | --- |
| 핵심 질문 | 당신은 누구인가? | 무엇을 할 수 있는가? |
| 프로세스 | 신원 검증 | 권한 검증 |
| 순서 | 일반적으로 먼저 일어남 | 인증 후 일어남 |
| HTTP 상태 코드 | `401 Unauthorized` | `403 Forbidden` |

## 인증

인증은 사용자가 누구인지 확인하는 과정이다.

로그인처럼 사용자의 신원을 확인하는 과정이 인증에 해당한다.

ex) GitHub에 로그인한다.

## 인가

인가는 인증된 사용자가 시스템 안에서 어떤 작업을 수행할 수 있는지 결정하는 과정이다.

사용자에게 정의된 역할, 사용자와 리소스의 속성, 사용자와 리소스 간의 관계를 기준으로 권한을 결정한다.

ex) 다른 사람의 리포지토리를 삭제하려고 하면, GitHub는 사용자가 누구인지 확인했지만 권한이 없기 때문에 차단한다.
